# To do Applikation-README

## Projektbeschreibung

### Dieses Projekt ist eine einfache ToDo-Applikation auf Basis von Node.js. Die Anwendung kann lokal sowie mit Docker und Docker Compose gestartet werden.

## Voraussetzungen
### Für die Verwendung des Projekts werden folgende Programme benötigt:
- Git

- Node.js und npm

- Docker

- Docker Compose

## Repository klonen

### Das Repository kann mit folgendem Befehl geklont werden:
### git clone https://github.com/USERNAME_GITHUB/docker-nodejs-sample.gitcd docker-nodejs-sample

## Paket installieren
### Nach dem Klonen werden die benötigten Node.js-Pakete installier, der Befehl lautet so: *npm install*

## Anwendung lokal auf dem Laptop starten
### Die Anwendung kann lokal mit folgendem Befehl gestartet werden: *npm start*
### Anschliessend kann die Anwendung im Browser geöffnet werden: http://localhost:3000
